# Live Readiness Checklist

进入小资金实盘前必须全部满足：

- [ ] 模拟盘连续运行 7 天无核心服务异常。
- [ ] 至少 20 个有效信号。
- [ ] 至少 5-10 笔模拟交易。
- [ ] 最大回撤小于 3%。
- [ ] 无任何风控越权。
- [ ] 100% 订单有止损。
- [ ] Agent JSON 解析成功率大于 99%。
- [ ] 通知、确认码 TTL、二次风控链路无异常。
- [ ] API key 已最小权限配置，提现权限关闭。
- [ ] 只开放一个市场、一个策略、一个品种。
- [ ] 起步 1x 杠杆。
- [ ] 每天最多 1-2 笔。
- [ ] Polymarket 地区限制检查通过；否则只观察。
- [ ] 实盘开关只由服务器 `.env` 或 Docker secret 控制。
- [ ] Agent/API 无权限修改实盘开关、API key、风控配置。

即使满足以上条件，也只允许极小资金、人工确认、低风险试运行。
